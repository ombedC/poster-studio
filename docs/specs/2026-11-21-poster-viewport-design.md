# 海报画板第一轮交互升级

视口使用真实 SVG 比例。100% 时 1 个根 SVG 单位对应 1 个 CSS 像素。适配屏幕独立计算比例并居中。滚轮缩放以指针为锚。空格左拖与中键平移共享指针生命周期。选框、原位编辑框和 Moveable 在视口变化后同步。

保留 SVG 写回路径。以根 SVG 和对象的屏幕矩阵换算位移，微调以根 SVG 为单位。吸附使用约 5 CSS px 容差，目标为画板边、中线及其他可见可编辑对象。自定义手势可直接计算吸附并绘制洋红辅助线。背景及锁定对象排除。外置悬停框和坐标 HUD 随交互状态清理。

文字角点等比缩放写入字号与所属行距。相对字号单位自然缩放，独立绑定的文字字段保持各自样式。鼠标手势一次提交，微调按 400ms 合并，历史使用清理后的 SVG 及业务状态。原位编辑 Esc 提交文字并保持选中。普通 Esc 清除选中。输入、输入法、弹窗和 AI 工作台隔离画板快捷键。

底部浮层提供缩放预设、参考线状态与快捷键速查。导出仍序列化 SVG 并由 Playwright 渲染 2 倍 PNG，编辑覆盖层处于 SVG 外。使用浏览器测试验证视口和选框、微调与焦点、文字等比缩放、PNG 像素，并回归双工作台、导入、坑位和本地字体。
