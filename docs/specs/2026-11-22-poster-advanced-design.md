# 海报画板第二轮提效

用逻辑对象集合表示多选，并沿用单选面板和 SVG 矩阵写回。拉框与可见对象求交。移动、微调、对齐和等距分布共享位移工具。层序只在同一父容器内变更，保护背景并跳过无变化操作。

拖动支持八方向约束和一次性复制。副本拥有独立 ID，保留绘制和裁剪引用，从业务字段解绑。SVG 文档及撤销快照保留实际节点、锁定和层序，增量回填在现有文档应用业务值。

固定头像外框裁剪，隔离态写回图片的内部位置与大小。文件拖入复用素材上传，头像覆盖，二维码完整显示。编辑工作台拦截文件拖放默认导航。吸管优先使用系统取色，纯色 SVG 填充作为回退。

界面覆盖层全部在内容 SVG 外。键盘操作受模式、焦点、输入法与弹窗约束。Playwright 覆盖成组移动与撤销、副本独立性、锁定和图层边界、头像调图与成品导出。
